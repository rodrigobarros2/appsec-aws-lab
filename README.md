# appsec-aws-lab

Laboratório de AppSec e DevSecOps para um SaaS serverless na AWS (API Gateway, Lambda, SQS, DynamoDB, S3, KMS, Secrets Manager, WAF), com uma versão **vulnerável de propósito** e a versão **corrigida**, e uma esteira de segurança que prova que pega cada falha.

Dados 100% fictícios. Documentação completa em construção.
